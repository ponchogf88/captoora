# Cómo arrancar un agente (cualquier modelo)

No le pidas que “se meta a tu cabeza”. Le das **un carril + dónde leer**.

## Si el proyecto YA existe (ej. Captoora)

Pega esto al inicio del chat:

```
Proyecto: Captoora. Un solo carril.
Lee en https://github.com/ponchogf88/captoora
en este orden: START_HERE.md → USER.md → SOUL.md → IDENTITY.md → AGENTS.md → CONTEXT.md
YO canónico (largo) está en Drive MY PROJECTS / READMEFIRST.rtf — no lo copies al repo público.
No inventes handles. No publiques en @jagf87. Si digo “ya”, ejecuta.
Tarea de esta sesión: [UNA FRASE]
```

Grok en esta app ya tiene GitHub y Drive conectados: puede leer el repo solo.
ChatGPT / Claude: o pegas el mismo bloque, o les das acceso al repo, o les pegas USER + CONTEXT.
Grok Bot en la Mac: apunta a `/Users/imac/Desktop/Projects/CAPTOORA.STUDIO` + este repo.

## Si vas a ABRIR un proyecto nuevo

1. Carpeta en Desktop/Projects + Drive MY PROJECTS + repo GitHub.
2. Copia la plantilla: IDENTITY, AGENTS, CONTEXT, SOUL, PROJECT, START_HERE.
3. No copies READMEFIRST entero a cada repo. El YO vive una vez.
4. El primer mensaje al agente es el bloque de arriba, cambiando nombre y URL.

## Qué no hacer
- No empieces el chat con el CV.
- No le pidas que adivine el @.
- No abras Kiteo en un chat de Captoora.
