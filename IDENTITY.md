1. **Monograma** — C de apertura + destello (flash). Archivo fuente: Drive / usuario `IMG_2104.jpg`. Vector placeholder: `assets/captoora-mark.svg`.

4. Slogan `Momentos que permanecen` es tagline, no parte del logo.
