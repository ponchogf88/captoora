# Buzón Legal de Referencias Visuales (`referencias/inbox/`)

Flujo oficial y 100% compatible con cumplimiento (**Legal Engineer**) para analizar Reels/TikToks de inspiración (ángulos de cámara, zooms, susurros, diseño sonoro y fondos) **sin usar scrapers pirata, robo de cookies ni evasión de login/CAPTCHAs**.

## Cómo enviar una referencia en 3 segundos

1. En tu iPhone o Mac, guarda una **grabación de pantalla breve (5–15 s)** o capturas del Reel que te gustó mientras lo ves en tu sesión normal.
2. Envíalo por **AirDrop** o guárdalo directo en esta carpeta (`referencias/inbox/`, también visible en iCloud Drive bajo `WATERS_SERIE/waters-serie/referencias/inbox/`).
3. Nómbralo de forma clara si quieres, por ejemplo: `2026-11-20_cuenta_zoom_susurro.mp4`.
4. Abre un **chat nuevo** (para cuidar tu cuota desde 0 tokens) y escribe:
   > *"Analiza cuadro a cuadro y el perfil de audio de `@proyectos/waters-serie/referencias/inbox/<archivo>` para replicar su estilo en `waters-3d-studio`."*

## Publicación y programación oficial (`@captoora.studio`)

- Para **publicar y programar tus propios 14 Reels semanales** de forma automatizada, la vía autorizada es la **Instagram Graph API oficial de Meta** (cuenta Professional/Creator conectada a Facebook Page, token en `SECRETS/` o Keychain — nunca en el repo), operada desde **n8n**, un **MCP conectado exclusivamente a la API oficial de Meta** o herramientas autorizadas (Metricool/Buffer).
